因此，我们以 Q’uo 的原则向您致意，我们以一位无限造物主的爱与光来问候您，我们今天来到您的面前是为祂的服务。我们可以说，我的兄弟，能有机会就您可能被召唤到的新方向这一问题与您交谈，真是何等的殊荣。这是一个令人喜悦的话题，因为它开放、坦率，并且触及事物的核心，释放和拥抱存在之物以及将要存在之物。

此刻我们只想向您提出一件事，那就是当您聆听这些谦卑的言语时，您能够放下任何关于我们以任何方式凌驾于您的想法。我们可能有意见，我们非常乐意分享我们所知道和思考的一切。然而，知识和真理难道不是一个非常主观的东西吗，我的兄弟？因此，尽管我们的目标是直接与您的灵魂对话，但同时我们也意识到有些箭会射偏靶心。所以，请在聆听时，注意摒弃那些此刻对您没有共鸣的想法。理解了这一点，我们将能自由地表达自己，而不用担心侵犯您意志和过程的自由。

在新方向的问题中，包含了一个假设，即旧事物可能需要被舍弃。因为正如 C 写给这个媒介的一封信中所写的那样，似乎存在一种模式，人们在没有恰当地评估自己在那些曾经看似是新方向、并曾充满热情和喜悦地追随的活动网络中的重新定位的情况下，就采纳了新的方向。然而，在一个生命中能量是有限的，而智慧的实体不会回头看，而是向前看，因为现在以及现在为自我的未来播下的种子，都存在于当下之中。因此，这种关切公正地被带到了寻求自我进化的者的面前。所以，我们想问 C，这个实体能对棋盘上每一项事务的热情做出何种真正的评估呢？我们是否可以将其视为一个被移动的棋子，它占据了棋局玩家愿意投入并有时间投入的时间和能量？那个特定游戏（正确生活）中的那枚棋子的和谐是什么？或者更进一步地，相对于棋盘上的其他棋子，在“正确行动”的游戏中如何移动？

这个媒介最近被鼓励对那些萦绕在她的心头和脑海中的事物进行此类评估，她发现当用专注和分析的心态审视它们时，它们很容易被归类到几种不同的方式中。最终，这个媒介选择的标准主要是热情。问题变成是关于她感到热情的那些事情。她如何根据重要性对它们进行排序？正是这次练习使这个媒介摆脱了持续的不知所措感和被那些在她的日程表上的事物卷走的感受，我们可以有益地建议，这种策略可能是更深入、更细致地评估此时此刻丰富而充实的生活内容的初步步骤。正如 C 所指出的那样，有些事情确实需要从车厢后部掉下来，但为什么以及按什么顺序？这种有意识的、基于智力的分析无法深入，无法潜入此类查询所预设的根本问题的本质。然而，它或许能以某种有益的方式，在头脑中组织和排列一个情景图景，从而在智力层面上获得对整体的把握。

在更深入地探讨新方向以及我们可以对它们说些什么时，您可能预料到我们会无法就新的方向给出具体的说明，因为做您的工作不是我们的职责。我们也不会从您那里夺走那份巨大的特权和责任。面对生命中的这个问题是一种荣誉，它预设了一种“有意义的土壤的生活”，正如诗人所说的 1，那种深入挖掘自身以产生被重视且有他人认可历史的价值之物的生命。因此，当一个人想要拥抱新的方向时，在这样的凝视中存在着一些更深层次的问题。人们希望审视 C 的习惯性思维过程，审视自我随时间的变化，观察那些重复出现的思维模式，并开始与之共处，识别这些思想的主题。很多时候，已经使用过、甚至被充分使用的模式，因为情感而被保留在活跃的头脑中，在某些情况下，需要根据自我的生命和能量中心进行重新评估，这个中心似乎正在向前移动，试图以新的方向和新的思维与存在方式去发展。

您不将这些事情仅仅视为数量。对于每一条探究的线索、每一个有益地花费时间的途径，都是一个充满品质的整个世界，而不仅仅是一个事实单位。当事物被珍视时，它们远不止是事实。当进步的途径被珍视时，它们远不止是街道。每一次转向和每一个新项目都暗示着一种光环、一种存在感、一个世界。此刻 C 需要哪些道路来学习和服务？这是正确的问题，我们相信这正是您所问的。但请认识到，您询问的是一个比仅仅可以用表达数量或本质的陈述所能描述的要微妙和复杂得多的事物。

我们将回到我们之前讨论过的那个词，那就是“热情”。确定自己热情的中心总是很有益的，为了做到这一点，通常有必要放下所有关于自我的假设，并从对自我的简单探究开始。

上个周末，这个媒介在固定的周日下午进行团体冥想时进行了引导，当时小组中的几位成员也向我们提出了一个非常相似的问题，他们也在思考新的方向，就像 C 一样。对于他们以及您，我们讨论了这个媒介正在经历的体验：她居住的房子里的布线被重新做了，因为以前的布线不足以承载她想在房子里做的事情所需的足够电力。当打算采取新方向时，通常在能够遵循之前，必须在人格之屋中发生一个解构期，可以说，是自我（ego）的解构，那些构成自我的外壳的部分，有时需要被温和地评估，并可能以一种更有利于讲述居住在人格、名称和身份之屋中的存在本质的方式进行重新定位。因此，我们建议您温柔地反思一下那个能量实体——您自己，人格的核层，生活经验表面的层次。问问自我：“我是谁？什么最深刻地感觉是我的一部分？另一方面，什么开始感觉像是一个我正在扮演的角色、一个我戴的面具、一个即使是真实的也变得非常令人厌倦的名声？”通常别人的期望，无论多么令人愉悦和奉承，也是那些无意识地限制了自我的基本能量不走出这个媒介所说的共识现实及其思维惯例的因素。

在寻找结果时，常常有益的是不要忘记对本质的探寻。结果是几乎作为那个实体过程的衍生品出现的，该实体的过程在于遵循那个本源存在的需要和您所拥有的能量的共鸣。当卷入言语表达和各种推理的喧嚣和踢踏舞中时，在词语的外壳和表面华丽的、易于流利的意义之下，无论多么吸引人，都潜藏着一个饥渴而渴望的灵魂和精神，其本质渴望探索的不是更远，而是更深；不是更广，而是更专注。当日常意识的探照灯被迷住并被引诱去关注一次深刻的内在探寻的焦点时，那束聚光灯可能会变得更加锐利，描绘出表面上不可能或绝对不可能看到的大量事物。

在某些情况下，这是一种几乎是诱使自己脱离思考的喜悦，进入一种完全顺服于那个接纳自我的奥秘以及如果允许自我如造物主为你所准备的那样绽放时可能做到的无限可能性的黑暗状态。并非说对您有唯一的命运或唯一正确的选择。恰恰相反。从一个普遍的化身设计来看，确实有一个命运，但实现该设计的机会在每个角落都爆发着，因此可能性永无止境，正如这个媒介会引用老沙基尔赞美诗所说的，“来得正好”。2

此时有不止一种合适的配置。然而，需要选择一个，我们鼓励 C 深入探索他内在未知的那个国度。这可以通过一些简单的练习来实现，这个媒介在类似情况下不时做过这样的练习。这个简单的练习是站在镜子前凝视，不是凝视自我，而是凝视眼睛，更确切地说，凝视左眼，选择一只眼睛并在其中凝视。这是一种有助于聚焦的技术，它将实体从“看一个图像或形式”的态度转移到“看进入一种本质”的态度。因为在眼睛的光芒中存在着那一位无限的造物主，而那光芒是一个微小的全息单元。

我们暂停一下，等待这个媒介和 V 之间两只争吵的猫被移开。

我们再次与这个媒介在一起。凝视镜子就是凝视造物主的眼睛。在您能够看到的那个闪光的瞬间中，在镜子里的那只眼睛里，蕴含着“恋人”3 的目光，它已化为血肉，并渴望发现它能找到什么。这就是您的探寻。存在和学习，然后，带着您所学到的收获，将您的观察的礼物献给那位无限的造物主。因为在了解自己时，您给了造物主一个机会去以越来越丰富的理解细节来了解祂自身。

当您处于这种状态时，您只需安于连接，以便您心中的事物可以被那个存在于您所看到的镜中光芒中的指引网络所询问。这是一种非常物理的方式，为您识别出居住在您体内、存在于您身体内，但比您身体的任何细胞都更接近您的意识。因为正是那种本质构成了您，而从它身上可以纺织出成千上万或数百万个体验化身的身体。当您凝视眼睛中的那束光时，那就是一切。因此，您可以直接接触到那些无法被智力把握的事物，即万物真正合一，并且您需要的所有信息都会在您需要的时候来到您身边。安于这种凝视和接收，直到您开始将自己感知为意识，而不是物理眼睛的“你”，而是那个永恒公民、来到这个特定地点在这个特定时间来做某些事情的伟大、普遍的眼睛。

当她阅读 C 如此亲切地发给她的非常有帮助的笔记时，这个媒介感到震惊，那篇关于写歌的查询中，对歌曲创作的评估只考虑了一个标准，那就是这些歌曲和剧本可能获得大众成功的可能性。为什么呢？C 想知道，如果它在创造那个媒介所称的“金钱”的绿色能量方面如此不恰当，会有写作这些东西的冲动吗？然而，我们想告诉 C，虽然您希望写歌或剧本是事物的形式，但您想要传达的是什么本质呢？达到七十岁这个年纪，一个好的时机是转向形而上学而非世俗，转向哲学而非实际，转向内在世界的本质而非外在世界——那个包含意识根源的内在世界。不能说外部成就没有任何坏处。通常，对世界的这种外部馈赠是最需要的、最受赞赏的以及最有益于减轻地球意识负担的。然而，很多时候，一个人为地球、为其人民所做的化身服务的本质，其意义不在于外部的馈赠，而在于内在的馈赠及其发展。在努力变得富有成效的过程中，自我常常没有被允许完全绽放。那些绽放的事物，那些看不见的事物，也会减轻地球的负担。

因此，我们鼓励 C 拓宽视野，以便有更多需要评估的点和更深层次的谜题需要解决。我的兄弟，我们不希望为您解决这个问题，但我们希望您看到这个问题的公正性及其影响的深度。我们祝愿您在带着充分意识地认识到自己自由去创造真正适合自己的环境来绽放的这种选择时刻中获得巨大的喜悦。

我们是 Q’uo 的成员，了解您的疑问，我的兄弟。我们可以讽刺地说，这个星球的人口已经在减少的过程中了。因为当新诞生的实体进入化身时，它们的细胞结构会以某种方式发生改变，以便更好地使它们能够享受第四密度的振动，这些振动在您星球的第三密度中正变得越来越透明。

我们无法提供关于实体可能突然从您所知的地球或盖亚上移除的信息。只有可能性，或者正如 Ra 所称的，是可能性/概率 [涡流]。您的民族有着广泛的未来可能性。我们可以说的是，仅仅因为自这个新千年开始发生的事件，很多事情已经改变了，因为虽然外部情况似乎变得越来越黑暗，但关于其人民光亮的情况有所改善，因为局势的纯粹黑暗以及相对简单地识别黑暗与光明，帮助加速了那些可以说是犹豫不决、半睡半醒的人的觉醒步伐。

一些模式的纯粹荒谬性就像闹钟上的“稍后提醒”，说：“再醒来一分钟看看这个东西。然后你就可以继续睡觉了。”然而，一个接一个的“稍后提醒”必须让人进入一个更清醒的状态，在这种状态下，行星疯狂的潜在模式开始变得更加明显。因此，我们完全不知道实体将以什么速度继续觉醒，以及随之而来的行星大气层光亮会以多快的速度引发这个媒介所说的“第一百只猴子效应”，4从而导致所有类型的行星政策发生快速的积极变化。这可能发生，也可能发生那些会引发地球上人类人口快速减少的事件。
